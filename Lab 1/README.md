
## 1. Variable Declaration

**Aim:** Declare variables and display their data types.

**Logic:** Create variables with different data types and use `type()` to check them.

**Sample Input / Output:**

```

No input

Name Type: <class 'str'>
Age Type: <class 'int'>
Height Type: <class 'float'>
Student Type: <class 'bool'>

```

## 2. Greeting Program

**Aim:** Take name, age, and city as input and print them using an f-string.

**Logic:** Take three inputs and combine them into one sentence using an f-string.

**Sample Input / Output:**

```

Ishaan
21
Gwalior

My name is Ishaan, I am 21 years old, and I live in Gwalior.

```

## 3. Arithmetic Operations

**Aim:** Perform basic arithmetic operations on two numbers.

**Logic:** Take two integers and calculate sum, difference, product, quotient, and remainder.

**Sample Input / Output:**

```

10
3

Sum: 13
Difference: 7
Product: 30
Quotient: 3.3333333333333335
Remainder: 1

```

## 4. Celsius to Fahrenheit

**Aim:** Convert Celsius temperature to Fahrenheit.

**Logic:** Take Celsius as input and apply the formula `(C × 9/5) + 32`.

**Sample Input / Output:**

```

25

Temp in Celsius: 25.0
Temp in Fahrenheit: 77.0

```

## 5. String Manipulation

**Aim:** Perform basic operations on a given name.

**Logic:** Take a name and use `upper()`, `lower()`, `strip()`, and `len()` on it.

**Sample Input / Output:**

```

Ishaan Sharma

Uppercase: ISHAAN SHARMA
Lowercase: ishaan sharma
Without extra Sidespaces: Ishaan Sharma
Length: 13

```
