## 📝 Quick Revision
- Dictionaries store data as key-value pairs.
- Dictionary keys must be hashable.
- `dict[key]` raises a `KeyError` if the key is missing.
- `dict.get(key)` returns `None` by default if the key is missing.
- `.update()` adds or modifies key-value pairs.
- Dictionary comprehensions provide a concise way to create dictionaries.
- Dictionary lookups take **O(1)** average time.
- Iterating through a dictionary while deleting elements can cause unexpected behavior; iterate over a copy when needed.
